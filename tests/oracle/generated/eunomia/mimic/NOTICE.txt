MIMIC-IV demo data in the OMOP Common Data Model (version 0.9)

The database file cdm.sqlite in this folder is the 100-patient MIMIC-IV demo in the OMOP CDM,
as distributed by the R package Eunomia 2.1.0 (OHDSI EunomiaDatasets, datasets/MIMIC).
Its source is PhysioNet: https://physionet.org/content/mimic-iv-demo-omop/0.9/
